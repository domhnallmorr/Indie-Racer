# Painting a livery

`template.svg` is a 2048 x 2048 UV wire template. Each named SVG group corresponds to one painted mesh (Nose, SidepodLeft, SidepodRight, EngineCover, wings, endplates, etc.). `layout.json` lists those names, paint materials and UV bounding boxes. The two sides are separate, not mirrored. All panels use the same atlas.

Open the SVG in a painting/vector editor, keep its wire groups on top as guides, and paint on layers underneath. Hide the wire guides before exporting the finished 2048 x 2048 PNG. Add at least 8 pixels of colour bleed around the islands to avoid mipmap seams. Blender's UV Editing workspace can show the selected part against the same atlas. `base_white.png` is the neutral default texture, not a finished colour scheme.

To apply artwork later, call this after the car's default roster colour has been assigned:

```gdscript
var skins = preload("res://content/vehicles/open_wheel/liveries/apply_livery.gd")
skins.apply(vehicle.get_node("Visual"), load("res://path/to/finished_skin.png"))
```

This duplicates the two paint materials per instance, installs the same image in both, and resets their tint to white so the artwork retains its colours. Rubber, mechanical parts and driver helmet are unaffected. No skin picker or roster texture field is added in this update.

The mesh generator packs the atlas; geometry changes and rebuilds may repack it. Finish body edits before producing final artwork, and version the GLB, template and skin together. A diagnostic checker render is generated by `tools/capture_car_2001.gd` in `builds/car_2001_uv_check.png`.
